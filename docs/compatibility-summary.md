# Compatibility Summary

This is a public, product-facing status summary for `pire-browser@0.2.2`. Detailed private development records are not published in this repository.

| Area | Status | Notes |
| --- | --- | --- |
| Install and setup | Supported | Global, project, and source installs are documented for the Firefox-backed package. `install --with-deps` accepts agent-browser-style setup recipes, can install Firefox through winget/Chocolatey on Windows or Homebrew on macOS when missing, and reports non-Snap/non-Flatpak guidance on Linux; `doctor --json` and `install-status --json` include concrete `nextActions`; `doctor --fix` provides an explicit setup repair path, and installed npm/Pi users can use `upgrade` or the lower-level `update` commands. |
| MCP agent integration | Supported | `pire-browser mcp --tools core` exposes a compact inspect-before-act stdio MCP workflow, including agent-browser-style typed get/check and wait tools plus action/tab/frame aliases. Agent-browser-style profiles `network`, `state`, `debug`, `tabs`, `mobile`, `react`, and `all` can be selected or comma-combined to expose broader typed tools on demand. |
| Core navigation and refs | Supported | Open, agent-friendly URL/active-tab reads including active-tab URL-backed `--llms`/markdown fetches, snapshot, refs, covered-click diagnostics, click, best-effort tap-as-click, best-effort swipe-as-scroll, double-click, hover, focus, select, check/uncheck, scroll, scroll-into-view, fill, type, press, focused keyboard edges, get, wait, and tab workflows are available. |
| Selectors and snapshots | Supported | CSS, text-style selectors, semantic locators, interactive snapshots, compact output, snapshot text diffing, URL snapshot diffing, and screenshot pixel diffing are available. |
| Sessions, profiles, and state | Partial | Named sessions, managed profiles, safe Firefox profile import by copy, plaintext or opt-in AES-256-GCM encrypted state files, active-origin cookies/storage, and Copy-as-cURL cookie import are available with Firefox-specific behavior. |
| Screenshots, files, and clipboard | Partial | Screenshots, image-backed PDF evidence, downloads with explicit output paths or configurable default download directories, chunked uploads capped at 8 MiB per command, and clipboard helpers are available; selectable-text PDF export, native file picker control, directory upload, and drag/drop upload are not. |
| Network and configuration | Partial | Domain allowlists, Firefox proxy settings, headers, session-memory HTTP Basic credentials, best-effort offline request blocking, best-effort viewport/device/geolocation settings, network diagnostics, metadata-only HAR start/stop/export, route mocks, and config defaults are available with documented limits. |
| Security guardrails | Partial | Domain, action, confirmation, content-boundary, output-size guardrails, optional encrypted state files, a built-in AES-256-GCM encrypted auth vault, and agent-browser-compatible credential-provider plugins for one-shot auth login are available. |
| Debugging and observability | Partial | Console, errors, best-effort JavaScript dialog handling, highlight, Firefox trace QA bundles, Firefox Performance Timeline profiler bundles, screenshot-sequence recording bundles, best-effort Web Vitals, best-effort React Fiber tree/inspect/render recording/Suspense, doctor, status, session inspection, recent redacted command activity, and the local status/session/activity dashboard with live read-only polling viewport preview plus start/status/stop lifecycle control are available; WebSocket viewport streaming, native WebM/video recording, remote input events, Chrome DevTools traces, and Chrome CPU profiling are not. |
| Cloud providers and alternate engines | Not supported | CDP, cloud browser providers, Chrome engine mode, Lightpanda, and iOS simulator support are not in the current package. |
