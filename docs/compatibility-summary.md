# Compatibility Summary

This is a public, product-facing status summary for `pire-browser@0.2.2`. Detailed private development records are not published in this repository.

| Area | Status | Notes |
| --- | --- | --- |
| Install and setup | Supported | Global, project, and source installs are documented for the Firefox-backed package. `install --with-deps` accepts agent-browser-style setup recipes, can install Firefox through winget/Chocolatey on Windows or Homebrew on macOS when missing, and reports non-Snap/non-Flatpak guidance on Linux; `doctor --json` and `install-status --json` include concrete `nextActions`; `doctor --fix` provides an explicit setup repair path, and installed npm/Pi users can use `upgrade` or the lower-level `update` commands. |
| MCP and chat agent integration | Partial | `pire-browser mcp --tools core` exposes a compact inspect-before-act stdio MCP workflow, including agent-browser-style typed get/check and wait tools plus action/tab/frame aliases. Agent-browser-style profiles `network`, `state`, `debug`, `tabs`, `mobile`, `react`, and `all` can be selected or comma-combined to expose broader typed tools on demand; the debug profile includes dashboard-backed `pire_browser_stream_enable/status/disable`. `pire-browser chat` provides a bounded AI Gateway-backed natural-language command loop when `AI_GATEWAY_API_KEY` is set, and the dashboard includes a non-streaming AI Chat panel using that same loop; streamed dashboard chat remains future work. |
| Core navigation and refs | Supported | Open, agent-friendly URL/active-tab reads including active-tab URL-backed `--llms`/markdown fetches, snapshot, refs, covered-click diagnostics, click, best-effort tap-as-click, best-effort swipe-as-scroll, double-click, hover, focus, select, check/uncheck, scroll, scroll-into-view, fill, type, press, focused keyboard edges, get, wait, active-page `setcontent` fixtures, and tab workflows are available. |
| Selectors and snapshots | Supported | CSS, text-style selectors, semantic locators, interactive snapshots, compact output, snapshot text diffing, URL snapshot diffing, and screenshot pixel diffing are available. |
| Sessions, profiles, and state | Partial | Named sessions, managed profiles, safe Firefox profile import by copy, plaintext or opt-in AES-256-GCM encrypted state files, active-origin cookies/storage, and Copy-as-cURL cookie import are available with Firefox-specific behavior. |
| Screenshots, files, and clipboard | Partial | Screenshots, image-backed PDF evidence, downloads with explicit output paths or configurable default download directories, chunked uploads capped at 8 MiB per command, file-input uploads, page dropzone uploads, and clipboard helpers are available; selectable-text PDF export, native file picker control, directory upload, and browser-chrome drag state are not. |
| Network and configuration | Partial | Domain allowlists, Firefox proxy settings, headers, session-memory HTTP Basic credentials, best-effort offline request blocking, best-effort viewport/device/geolocation settings, network request/response waits, diagnostics with redacted headers, redacted/truncated outgoing request bodies, and bounded text-like response previews when Firefox exposes them, HAR start/stop/export, route mocks, and config defaults are available with documented limits. |
| Security guardrails | Partial | Domain, action, confirmation, content-boundary, output-size guardrails, optional encrypted state files, a built-in AES-256-GCM encrypted auth vault, agent-browser-compatible credential-provider plugins for one-shot auth login, and read-only `plugin list/show` discovery are available; non-credential plugin capabilities are discoverable but not executed by the Firefox backend yet. |
| Debugging and observability | Partial | Console, errors, best-effort JavaScript dialog handling, highlight, Firefox trace QA bundles, Firefox Performance Timeline profiler bundles, screenshot-sequence recording bundles including `record restart`, best-effort Web Vitals, best-effort React Fiber tree/inspect/render recording/Suspense, doctor, status, session inspection, recent redacted command activity, `stream enable/status/disable`, and the local status/session/activity dashboard with polling preview plus WebSocket screenshot-frame streaming and basic remote input are available; native WebM/video recording, streamed chat updates, Chrome DevTools traces/screencast, and Chrome CPU profiling are not. |
| Cloud providers and alternate engines | Not supported | CDP, cloud browser providers, Chrome engine mode, Lightpanda, and iOS simulator support are not in the current package. |
