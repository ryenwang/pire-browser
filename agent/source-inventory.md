# Installed Source Inventory

This inventory describes the source sets expected in a public installed `pire-browser` package. It is not a repository file listing.

## Authoritative Installed Source Sets

- `bin/pire-browser.js`: public JS launcher that selects the optional native package.
- `pi/extensions/`: Pi extension wrapper and runtime helpers used by coding agents.
- `extension/manifest.json` and `extension/dist/`: Firefox extension manifest and built background assets.
- `agent/`: compact routing guidance for installed agents.
- `pire-browser.schema.json`: authoritative packaged config schema for `pire-browser` defaults.
- `agent-browser.schema.json`: legacy packaged schema filename alias kept for existing configs.
- `skills/pire-browser/SKILL.md`: small discovery stub for skill installers and agents.
- `skill-data/core/SKILL.md`: version-matched core skill served by `pire-browser skills cat core`.
- `scripts/pi-postinstall.mjs`, `scripts/pi-install-migration.mjs`: best-effort postinstall setup and Pi GitHub-to-npm package migration hooks.
- `LICENSE`: MIT license terms for the public package.
- `README.md`: public package overview and human-facing install notes.

## Generated Or Runtime Artifacts

- Native messaging manifests and registry entries are generated by `pire-browser setup`.
- Native binaries are supplied by optional platform packages such as `pire-browser-win32-x64`, not by the root npm package.
- Session state, encrypted auth vault/key files, confirmations, downloads, uploads, policies, screenshot-sequence recording bundles, dashboard state/log files, and bounded redacted activity logs live under standard OS state directories or explicit output directories, not in the npm package.
- Firefox profiles, profile-import metadata, and live sessions are runtime state and may be recreated.

## Excluded Maintainer Material

The public npm package should not ship repository-maintainer context such as `docs/`, repository test fixtures, or Pi tests. Those files are useful for development but noisy for installed agents.

## Known Ambiguity

- The installed package is version matched to its embedded skill content. If an agent sees local docs outside this installed package, prefer the files listed above unless the user explicitly asks for maintainer or repository context.
- State schema v1 is the current supported format. Future schema bumps must include migrations or clear unsupported-version errors.
